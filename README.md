# one-line-tetris
a one line URL tetris

use the URL provided under /dist/uri.txt, I cant seem to paste it here without it breaking.

controls are:

Left arrow key --> move left
Right arrow key --> move right
Up arrow key --> rotate
Down arrow key --> drop faster
